[size=5][b]Français[/b][/size]

[size=4][b]Ce que ça corrige[/b][/size]
Sur certaines installations Steam, le jeu affiche au démarrage que le DLC « Voix japonaises » est désactivé parce qu'il n'est pas téléchargé. Ensuite, impossible de charger sa sauvegarde : « Ces données de sauvegarde ne peuvent pas être chargées car elles incluent du contenu téléchargeable ».

Sauf que dans Vengeance, les voix japonaises ne sont plus un DLC. Elles sont incluses dans le jeu de base, on ne peut ni les acheter ni les télécharger à part. C'est un reste de la version Switch de SMT V, où c'était un vrai DLC.

[size=4][b]Ce que fait le mod[/b][/size]
Dans la table des DLC du jeu, les lignes « voix japonaises » et « voix anglaises » pointent vers un faux numéro d'application Steam ([b]9999999[/b]). Le jeu demande donc à Steam si on possède un DLC qui n'existe pas, et parfois Steam répond non.

Le mod remplace ce faux numéro par celui du jeu de base ([b]1875830[/b]), que tout le monde possède forcément. C'est tout.
[list]
[*]L'exécutable du jeu n'est pas modifié.
[*]Les vrais DLC (missions, packs, difficulté, précommande) ne sont pas touchés et restent vérifiés normalement.
[*]Vos sauvegardes ne sont pas modifiées.
[/list]

[size=4][b]Installation[/b][/size]
[b]Option 1 : le fichier .pak (le plus simple)[/b]
[list=1]
[*]Dans Steam : clic droit sur le jeu -> Gérer -> Parcourir les fichiers locaux.
[*]Ouvrez [b]Project/Content/Paks/[/b]
[*]Créez un dossier [b]~mods[/b] s'il n'existe pas.
[*]Mettez-y [b]zz_GhostDLCFix_P.pak[/b]
[/list]

[b]Option 2 : le patcher (Windows, macOS, Linux)[/b]
Il fabrique le .pak à partir de vos propres fichiers du jeu, et ne touche à rien si la table a changé. Pratique après une mise à jour du jeu.
[list]
[*]Windows : glissez le dossier du jeu [b]SMT5V[/b] sur [b]ghost-dlc-fix-windows-x86_64.exe[/b]
[*]macOS : [code]./ghost-dlc-fix-macos-universal "/chemin/vers/SMT5V"[/code]
[*]Linux : [code]./ghost-dlc-fix-linux-x86_64 "/chemin/vers/SMT5V"[/code]
[/list]
Sur macOS, si le système bloque le fichier : [code]xattr -d com.apple.quarantine ghost-dlc-fix-macos-universal[/code]

[size=4][b]Désinstallation[/b][/size]
Supprimez [b]Project/Content/Paks/~mods/zz_GhostDLCFix_P.pak[/b]

[size=4][b]Pourquoi j'ai fait ça[/b][/size]
J'avais le jeu et tous les DLC achetés sur Steam, et je ne pouvais plus charger ma seule sauvegarde à cause d'un « DLC » qui n'en est pas un. Le bug n'a jamais été corrigé, d'autres joueurs l'ont eu aussi, et il n'existait pas de solution. Alors je l'ai faite.

Testé sur la build Steam 17140961. Code source : [url=https://github.com/AnnoyedDev/Ghost-DLC-Fix-for-Shin-Megami-Tensei-V-Vengeance]GitHub[/url]

[size=5][b]English[/b][/size]

[size=4][b]The problem[/b][/size]
Some people on Steam get a popup when they start the game, saying the Japanese Voice DLC was disabled because it isn't downloaded. Then, when you try to load a save, the game refuses because the save "includes downloadable content".

Thing is, Vengeance ships with Japanese voices out of the box. There's no Japanese voice DLC to buy or download on Steam. It's left over from the original Switch release, where it was sold separately.

[size=4][b]How it works[/b][/size]
The game keeps a small table with every DLC and its Steam app ID. The Japanese voice and English voice rows still use a placeholder ID, [b]9999999[/b], which isn't a real app. So when the game checks with Steam, it can come back as "not owned".

This mod points both rows to the base game's ID ([b]1875830[/b]) instead. If you own the game, you own that ID, so the check goes through.

Nothing else gets touched:
[list]
[*]no changes to the exe
[*]the paid DLCs are still checked like before
[*]your saves stay as they are
[/list]

[size=4][b]How to install[/b][/size]
[b]The easy way: the .pak[/b]
[list=1]
[*]In Steam, right-click the game -> Manage -> Browse local files
[*]Open [b]Project/Content/Paks/[/b]
[*]Make a folder called [b]~mods[/b] (skip this if it's already there)
[*]Put [b]zz_GhostDLCFix_P.pak[/b] inside
[/list]

[b]Or: the patcher (Windows, macOS, Linux)[/b]
It reads your own game files and makes the .pak for you. If an update ever changes the DLC table, it stops instead of writing something broken.
[list]
[*]Windows: drop the [b]SMT5V[/b] folder onto [b]ghost-dlc-fix-windows-x86_64.exe[/b]
[*]macOS: [code]./ghost-dlc-fix-macos-universal "/path/to/SMT5V"[/code]
[*]Linux: [code]./ghost-dlc-fix-linux-x86_64 "/path/to/SMT5V"[/code]
[/list]
If macOS won't let you open it: [code]xattr -d com.apple.quarantine ghost-dlc-fix-macos-universal[/code]

[size=4][b]Removing it[/b][/size]
Just delete [b]Project/Content/Paks/~mods/zz_GhostDLCFix_P.pak[/b]

[size=4][b]Why[/b][/size]
I bought the game and all the DLC on Steam, and still got locked out of my only save over a "DLC" that doesn't even exist. It's been broken like this for a while, other people have run into it, and nobody had a fix. So here's one.

Tested with Steam build 17140961. Source: [url=https://github.com/AnnoyedDev/Ghost-DLC-Fix-for-Shin-Megami-Tensei-V-Vengeance]GitHub[/url]

[size=5][b]日本語[/b][/size]

[size=4][b]どんなバグ？[/b][/size]
Steam版で、ゲームを起動したら「日本語ボイスのDLCはダウンロードされてないから無効にした」みたいなメッセージが出て、セーブを読もうとすると「ダウンロードコンテンツが入ってるからロードできない」って言われる。そういうバグ。

Vengeanceは日本語ボイスが最初から入ってるから、そもそもDLCとして売ってない。Switchの元のSMT Vのときのしくみが、そのまま残っちゃってるだけ。

[size=4][b]中身の話[/b][/size]
ゲームの中にDLCの一覧があって、それぞれにSteamのアプリ番号がついてる。日本語ボイスと英語ボイスだけ、仮の番号「[b]9999999[/b]」のまま。そんなアプリはないから、Steamに聞くと「持ってない」になることがある。

このMODでは、その2つをゲーム本体の番号「[b]1875830[/b]」にしてある。ゲームを買ってれば絶対持ってる番号だから、チェックで止まらなくなる。

ほかはさわってない：
[list]
[*]exeはそのまま
[*]お金を払うDLCのチェックは今まで通り
[*]セーブデータもそのまま
[/list]

ゲームもDLCも全部Steamで買ったのに、ありもしない「DLC」のせいで一個しかないセーブが読めなくなった。けっこう前からこのままだし、ほかにも困ってる人がいるのに、直し方が見つからなかった。なら自分でやるか、って感じ。
